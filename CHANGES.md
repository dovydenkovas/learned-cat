# Изменения

## Планируемые изменения

### Добавлено
- [ ] Добавлены сценарии автодополнения для bash, zsh.
- [ ] Добавлена поддержка systemd и openrc для управление работы learned-cat-daemon.
- [ ] Добавлена команда `learned-cat-daemon status`, выводящая статистику работы и текущее количество активных пользователей.
- [ ] Добавлена команда `learned-cat-daemon reload` и соответствующая команда `systemctl reload learned-cat-daemon` для повторного чтения настроек без остановки сервера.
- [ ] Добавлена возможность управления результатами тестирования.
Команда `learned-cat-daemon control` позволяет:
- Удалять результаты тестирования пользователей.
- Маскировать конкретный результат тестирования. Тогда результат остается в базе данных, но не учитывается при подсчете количества попыток и лучшего результата.
- [ ] Добавлена опция `--best` для команды `learned-cat-daemon export-marks`, выводящая информацию о результатах с максимальным баллом.
- [ ] Добавлена поддержка пакетных менеджеров: pacman, apt, emerge.
- [ ] Добавлена локализация интерфейса в зависимости от системных настроек, языки: русский, английский.
- [ ] Добавлены дополнительные unit тесты.
- [ ] Добавлен файл DEVELOPMENT.md, в котором располагаются технические подробности о структуре программы.

### Изменено
- [ ] Изменено расположение файлов. Файлы настроек и тестов располагаются в /etc/learned-cat, логи и результаты тестрования в /var/lib/learned-cat.
- [ ] Переработан сценарий установки.
- [ ] Изменен порядок взаимодействия с программой. Теперь при установке демона добавляется пользователь и группа learned-cat. learned-cat-daemon должен запускаться пользоавтелем learned-cat, при этом все члены группы learned-cat-daemon имеют доступ к каталогам /etc и /var и могут настраивать тесты и смотреть результаты.
- [ ] Актуализирована документация.
- [ ] Команды export-marks и export-variants выводят информацию к поток стандартного вывода, для вывода в файл используйте

### Исправлено
- [ ] Установлен запрет на одновременный запуск двух тестов одним пользователем.
- [ ] Корректное отображение форматирования вопросов (раньше съедались пробелы в начале строки). 

## [v0.2.0]

### Добавлено
- [x] Добавлено логирование запросов, включающее разные уровни.
- [x] В Makefile были добавлены скрипты установки, удаления и обновления программы в среде linux. При использовании systemd добавляется служба learned-cat.
- [x] Написаны тесты для ключевых модулей системы, что повышает её надежность.
- [x] За вопросы с несколькими ответами рассчитывается дробный балл.
- [x] В настройках сервера вместо списка разрешенных пользователей можно указывать путь к текстовому файлу, содержащему перечень пользователей.
При этом имена в файле должны быть перечилены без знаков препинания через пробел или символ переноса строки.
- [x] Варианты тестирования сохраняются в базе данных, их можно экспортировать.

### Изменено
- [x] Результаты тестирования теперь хранятся в sqite базе данных. Это позволяет уменьшить объем потребляемой оперативной памяти и упращает данные, обрабатываемые сервером при выполнении тестирования, что ускоряет скорость работы сервера.
